# DJF RENOVATION LTD — Official Web Platform

Professional, high-performance website for **DJF RENOVATION LTD** (Calgary, AB), featuring architectural drywall, commercial steel framing, glazing, technical caulking & joint sealing, concrete repairs, and firestopping.

## 🚀 Features & Stack
- **Modern Architecture**: Clean vanilla HTML5 + Tailwind CSS + Google Fonts (Outfit & Inter).
- **Smooth Momentum Scrolling**: Lenis smooth scroll engine.
- **Micro-Animations & 3D Depth**: GSAP 3 + ScrollTrigger batch reveals, hero scrub, and interactive 3D perspective tilt cards.
- **On-Site Field Reels**: 3 optimized vertical video reels (`9:14` aspect ratio) with mute/unmute audio controls.
- **Monetization**: Integrated Google AdSense responsive ad units and Auto-Ads tags (`ca-pub-7206413484396748`).
- **Interactive Cost Calculator**: Client-side estimation calculator for drywall, framing, and renovation scopes.
- **Accessibility**: 100% compliant with `prefers-reduced-motion`.
